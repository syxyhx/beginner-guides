## 阅读顺序

下面这张图只是编号顺序，箭头不代表依赖——三篇互不前置：

```
01 GitHub 入门
   │  注册、装客户端、提交推送、学生认证（GitHub Education，独立体系）
   ▼
02 云服务器 + dsh
   │  阿里云/腾讯云账号、实名、买机器、初始化、部署、手机访问
   ▼
03 阿里云百炼 API
      领学生券、拿密钥、验证连通、控制费用
```

两个账号体系，别混：**02 和 03 用同一个阿里云账号**，实名和阿里云的学生认证做一次就行；**01 是 GitHub 账号**，它的学生认证（GitHub Education）走的是另一套，与阿里云无关，两边都得各自做一遍。

三篇之间没有强制依赖，按自己最急的那篇读即可。
