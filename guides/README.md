## 阅读顺序

```
01 GitHub 入门
   │  注册、实名、学生认证、客户端、提交推送
   ▼
02 云服务器 + dsh
   │  用同一个实名账号买机器、初始化、部署、手机访问
   ▼
03 阿里云百炼 API
      领学生券、拿密钥、验证连通、控制费用
```

三篇共用一个实名身份：01 里做完的学生认证，02 和 03 都不用再做一遍。所以**如果三篇都要读，从 01 开始最省事**。
