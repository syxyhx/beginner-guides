## 读之前

- 需要：一个能用的邮箱、一台电脑。
- 要顺带申请学生福利的话，再多准备一样能证明在读的材料——学校邮箱（`.edu.cn` 等）、学生证照片、学信网在线验证报告，三选一即可。
- 不需要：任何编程基础，也不必会用命令行。
- 篇幅不大，但**不必从头读到尾**：正文第 8 页有一页「阅读路线：三种使用姿势」，按自己是用网页、用桌面端还是用命令行，跳到对应章节即可。第五章里那次「10 分钟第一次实操」是一条完整的端到端闭环，想先跑通一次可以直接从那里开始。

## 四条容易踩的坑

1. **按自己的使用方式跳读**。正文第 8 页的「阅读路线」把使用姿势分成三种，网页 / 桌面端 / 命令行各对应不同章节，从头硬读是浪费时间。
2. **提交身份别写真实姓名**。写进 `user.name` 的名字会永久留在每一次提交记录里，建议用网名或拼音缩写。
3. **桌面端自带的 Git 不等于系统 Git**。想用命令行必须另外装一份 git-scm.com 的，桌面端那份只给它自己用、没加进系统路径，在终端直接敲 `git` 会提示「不是内部或外部命令」。
4. **密码和访问令牌不是一回事**。GitHub 早已不支持用账号密码推送，走 HTTPS 要在 Settings → Developer settings 里生成 Personal Access Token 代替密码。
