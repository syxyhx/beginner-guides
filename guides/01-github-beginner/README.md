# 01 · GitHub 新手学生使用指南

写给没碰过 Git 的学生：从注册账号、装客户端，到提交、推送、多人协作，按「一个完全不懂的人」的视角走一遍。

## 读之前

- 需要：一个能收短信的手机号、一台电脑、一个能用的邮箱。
- 不需要：任何编程基础，不需要会命令行。
- 全程大约 90 分钟；只求「能提交作业」的话，读完前两章即可。

## 三条容易踩的坑

1. **按自己的使用方式跳读**。正文开头有一页「阅读路线」，只用网页 / 用桌面端 / 用命令行，三条路对应不同章节，不必从头读到尾。
2. **提交身份别写真实姓名**。写进 `user.name` 的名字会永久留在每一次提交记录里，建议用网名或拼音缩写。
3. **密码和令牌不是一回事**。GitHub 早已不支持用账号密码推送，命令行要用 Personal Access Token，教程里单独讲了在哪生成。
