- 需要：一个已完成实名的云厂商账号（阿里云或腾讯云）、一台电脑、一个 SSH 客户端（Windows 自带终端即可）。

## 四条容易踩的坑

1. **端口放行不是「全开」**。手册 1.4 与 4.11 的口径统一为：走 Tailscale 组网方案时只放行组网网段 `100.64.0.0/10`，不要图省事对 `0.0.0.0/0` 开放管理端口。
2. **别全程用 root 操作**。1.6 的五步初始化里会建一个日常用户并加 sudo，这一步不要跳过。
3. **进程会随 SSH 断开而死**。4.6 用进程守护解决，装完再关终端。
4. **手机访问有安全排序**。4.7 给了三种方式并按安全性排序，优先选组网方案，其次才是公网端口 + 白名单。
