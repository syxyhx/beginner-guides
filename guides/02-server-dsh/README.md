## 读之前

- 需要：一个能收短信的手机号（注册云厂商账号用）、一台电脑、一个 SSH 客户端（Windows 自带终端即可）。账号不必预先实名，1.1 会带你走完实名——这一步必过，否则无法下单。
- 需要准备一笔预算：按手册 2.3 与 3.1 的 2026 年 10 月数据，学生机与轻量特惠款单年在 ¥49–199 之间。第 3 部分专讲怎么避免续费涨价，别跳过。
- 不需要：Linux 基础。所有命令都单独成行、可整段复制，照抄即可。

## 四条容易踩的坑

1. **端口放行不是「全开」**。1.4 与 4.11 的要求一致：管理端口绝不要对 `0.0.0.0/0` 开放。走 Tailscale 时 ufw 只放行组网网段 `100.64.0.0/10`（1.4 给了现成命令），确需临时直连就只填自己的公网 IP；连通性问题的排查口径见 4.11。
2. **别全程用 root 操作**。1.6 的五步初始化里第 4 步就是建一个日常用户并加 sudo，这一步不要跳过。
3. **进程会随 SSH 断开而死**。4.6 用进程守护解决，装完再关终端。
4. **手机访问有安全排序**。4.7 给了三种方式并按安全性排序：Tailscale 组网 ★★★★★ → Caddy 反代 + HTTPS ★★★★ → 公网 IP + 端口直连 ★（仅临时测试）。

## 与另外两篇的关系

- **不需要先读 01**。01 是 GitHub 账号，和云厂商账号是两套独立体系，学生认证也各做各的。
- **和 03 共用同一个阿里云账号，但接口默认不是百炼**。4.4 节主线走的是 **DeepSeek 官方 API**（`https://api.deepseek.com` + `deepseek-flash`），百炼只是在末尾一句「也可指向任何 OpenAI 兼容端点」里出现。想用 03 领的那张 300 元券，三项必须一起改：

  - `LLM_BASE_URL` → `https://dashscope.aliyuncs.com/compatible-mode/v1`
  - `LLM_MODEL` → 百炼控制台列出的模型名（qwen 系列），**不能沿用 `deepseek-flash`**
  - `LLM_API_KEY` → 03 里在百炼创建的那个 `sk-` 密钥

  只换密钥、不改地址和模型名，一定报错。想少折腾就先做 03，再按上表改 4.4。
