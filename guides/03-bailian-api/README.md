## 读之前

- 需要：已完成个人实名的阿里云账号、本人手机支付宝、有效期内的在校学籍（学信网可查）。
- 不需要：任何编程基础。验证连通性只用一条 `curl` 命令，复制粘贴即可。
- 券是限时活动，名额与规则可能随期调整，动手前请看云工开物页面的当期说明。

## 你最终只需要两样东西

| 要填的东西 | 值 |
|---|---|
| 接口地址（Base URL） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| API 密钥（API Key） | 在百炼创建的 `sk-` 开头那一长串 |

填进任何支持 OpenAI 兼容协议的客户端，客户端会自动列出可用模型，不需要手填模型名。

## 三条容易踩的坑

1. **密钥只完整显示一次**。创建成功后的弹窗关掉就再也看不到完整值，只能删掉重建。它等同于密码，不要发给任何人、不要截图发到群里。
2. **接口地址结尾必须是 `/compatible-mode/v1`**。少写一段、多写一段斜杠，都会表现成「客户端连不上 / 不列模型」。
3. **券用完不会自动停**。300 元用完或过期后，继续调用会按用量从账号余额扣费，记得设消费预警。
